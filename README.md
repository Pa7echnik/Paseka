# Песнь Пепла — интерфейс интерактивной книги

Атмосферный фронтенд для авторского книжного проекта в жанре тёмного фэнтези:
рукопись с читальным залом, картотека персонажей, кодекс лора, живая рисованная карта
мира с «сюжетной камерой», хроника событий, музыкальный раздел и настройки режима чтения.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # продакшен-сборка (dist/)
```

## Стек

- **React 18 + TypeScript + Vite**
- **Tailwind CSS v4** — токены дизайна на CSS-переменных (темы «Чернила» / «Пергамент»)
- **Framer Motion** — переходы разделов, line-mask появление заголовков, scroll-reveal
- **Three.js** — атмосферные частицы фона (искры и пыль, параллакс от курсора)
- **localStorage** — весь авторский контент и настройки

## Как наполнять книгу

### Главы
`src/data/chapters.ts`: поле `content` — абзацы через пустую строку;
`scenes` — ключевые сцены; `locationId` / `characterIds` связывают главу
с картой и героями (отображаются в справке читального зала).

### Персонажи и лор
Добавляются прямо в интерфейсе (кнопки «Добавить персонажа» / «Новая запись»),
хранятся в localStorage и переживают перезагрузку. Портрет — URL изображения
(можно положить файл в `public/images/` и указать `/images/имя.jpg`);
без портрета рисуется герб-заглушка.

### Карта
- Данные: `src/data/locations.ts` (`x`, `y` в координатах viewBox 1000×640).
- Новые места добавляются кликом по карте в режиме «Новая метка».
- **Сюжетная локация**: в карточке места кнопка «Отряд сюда» — маркер отряда
  переезжает, путь прокладывается пунктиром, камера мягко наводится на город.
  Хранится в `grim.v2.party`.
- Свою карту-подложку можно нарисовать прямо в `MapPage.tsx` (SVG-слой) —
  маркеры и камера работают поверх любой геометрии.

### Музыка
Положите файл в `public/audio/` и в `src/data/music.ts` укажите
`src: "/audio/tema.mp3"`. Трек `synth:wind` работает без файла —
это встроенный WebAudio-синтез (гул и ветер). Поля `boundChapterId` /
`boundLocationId` привязывают тему к главе или локации.

## Хранение

Ключи localStorage: `grim.v2.meta`, `grim.v2.chapters`, `grim.v2.characters`,
`grim.v2.lore`, `grim.v2.locations`, `grim.v2.events`, `grim.v2.party`,
`grim.v2.progress`, `grim.v2.settings`. Экспорт в JSON и сброс к демо-данным —
во вкладке «Режим» (настройки).

## Доступность и движение

Анимации уважают `prefers-reduced-motion` и отключаются целиком в настройках
(«Движение и анимации»): частицы становятся статичным кадром, плавные
переходы и камера карты — мгновенными.
